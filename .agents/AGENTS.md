# SOLV Server Tracker — Contexto y Reglas del Proyecto

## Qué es SOLV Server Tracker

Sistema de **Observabilidad Activa, ChatOps y AIOps** para infraestructuras Docker On-Premise.
Arquitectura dual y políglota con separación estricta entre **Data Plane** (Agente Host en Go) y **Control Plane** (Servidor / MCP en Python FastAPI).

---

## Stack Tecnológico (NO cambiar sin ADR)

- **Data Plane (Agente Host)**: Go 1.23+ (estándar `net/http`, Bubbletea / Lip Gloss para TUI, Docker Engine SDK / Unix socket `/var/run/docker.sock`, `zalando/go-keyring`).
- **Control Plane (Backend API)**: Python 3.12+ + FastAPI + Pydantic v2 + SQLAlchemy / asyncpg.
- **Base de Datos**: PostgreSQL 16+ / TimescaleDB (para series temporales de métricas).
- **IA / AIOps**: Servidor MCP (Model Context Protocol) nativo expuesto por FastAPI para Claude Code, OpenCode y Cursor.
- **ChatOps**: Telegram Bot API con botones interactivos y validación criptográfica de callbacks.
- **Criptografía**: HMAC-SHA256 para firma y verificación de cada payload entre agente y servidor.

## Decisiones Inamovibles y Blindajes (D1–D5)

1. **D1 - Control Remoto Seguro (Cero RCE)**: El Agente en Go inicia una conexión saliente reversa (WebSocket/gRPC seguro) hacia FastAPI. Whitelist estricta de acciones (`restart`, `stop`, `isolate_network`). **PROHIBIDO ejecutar comandos arbitrarios (`exec`)**.
2. **D2 - Fallback de Credenciales en Cascada**:
   - 1º: Keyring del SO (SecretService / D-Bus).
   - 2º: Si falla (headless/SSH), archivo local cifrado AES-256-GCM (`~/.solv/vault.enc`, permisos `0600`) derivado con Argon2id.
   - 3º: Variables de entorno directas para CI/CD y pruebas.
3. **D3 - Circuit Breaker Financiero Declarativo**: Configuración vía Docker Labels (`solv.egress.limit`, `solv.egress.action`, `solv.egress.window`). Si un contenedor no tiene labels, solo emite alerta (*dry-run*), nunca mata el contenedor a ciegas.
4. **D4 - Muestreo de Métricas con Ring Buffer**: Buffer circular en memoria en Go. Se descartan deltas si `system_cpu_delta <= 0` o si el contenedor reinició PID.
5. **D5 - Gobernanza y Seguridad en Telegram**: Allowlist estricta de `chat_id`/`user_id` + Tokens efímeros firmados con HMAC y TTL de 60s en los `callback_data`.

## PROHIBIDO

- **PROHIBIDO** exponer `/var/run/docker.sock` directamente a la red o a contenedores no privilegiados.
- **PROHIBIDO** usar archivos `.env` en texto plano en el host para el agente (usar la cadena de fallback segura).
- **PROHIBIDO** renderizar la TUI a más de 2 FPS en modo daemon (el daemon desacoplado debe consumir <0.1% CPU).
- **PROHIBIDO** acumular métricas en memoria sin límite cuando FastAPI esté caído (usar Ring Buffer FIFO fijo de máx 10 MB).
- **PROHIBIDO** añadir atribuciones de IA ("Co-Authored-By", "Generated by AI", etc.) en commits o código.
- **PROHIBIDO** usar imágenes `:latest` en docker-compose (fijar versiones explícitas).
