# SOLV v1.0.0 — First Public Release

Active observability, AIOps, and ChatOps for on-premise Docker infrastructure.

## Features

- **Ultra-lightweight Go Agent**: Under 0.1% CPU consumption, streaming metrics via raw Unix socket and ring buffer.
- **Encrypted Vault**: Zero plaintext `.env` secrets on host. Resolves via OS Keyring (SecretService/D-Bus) falling back to Argon2id-derived AES-256-GCM encrypted local vault (`~/.solv/vault.enc`, 0600 permissions).
- **AI Provider Registry**: Automatic discovery for local providers (Ollama, vLLM, LM Studio) and cloud endpoints (OpenRouter, OpenAI, Anthropic, custom OpenAI-compatible).
- **Diagnosis Modes**: AUTO, FAST, DEEP, and MANUAL with severity-based routing.
- **4-Level Degradation Cascade**: Graceful fallback `[AI]` -> `[AI~]` -> `[RULE]` -> `[SIG]` with 12 curated Docker rules operating 100% offline.
- **Interactive TUI**: Catppuccin Mocha aesthetic, split-pane navigation, container technical detail sheets, and live CPU/RAM/Network sparklines.
- **Incident Correlation**: Correlates multi-container cascading failures into single incidents. Identifies root causes with confidence tags (confirmed / probable / undetermined) and manual override.
- **Structured AI Output Contract**: JSON output schema with individual field recovery and FAST->DEEP re-execution on critical severity.
- **Visible Session Meter**: Tracks volatile request counts, tokens consumed, and estimated cost without persistent billing surprises.
- **Bilingual System (es/en)**: Unified language configuration across TUI, deterministic rules, AI model directives, and Telegram bot callbacks with industry glossary preservation.
- **Full Responsiveness**: 80 columns and 25 rows guaranteed design floor with panic trap TTY restoration and `crash.log`.
- **Zero RCE**: Remote remediation whitelist (`restart`, `stop`, `isolate_network`) strictly requiring user confirmation modals.

## Supported Platforms

- `linux/amd64`, `linux/arm64`: Official support (primary production targets).
- `darwin/arm64`, `darwin/amd64`: Best effort (provided as precompiled binaries, community reports welcome).
- `Windows`: Not supported natively (use Docker inside WSL2).

## Installation

### Automated Installation (curl | sh)

```bash
curl -sSL https://AlvaroRiveraCarhuani.github.io/server_tracker/install.sh | sh
```

The installer verifies SHA256 checksums, prompts for initial language preference, creates `~/.solv/config`, and installs `solv-agent` and `solv-update`.

### Manual Installation

Download the corresponding `.tar.gz` and `.sha256` from the release assets below, verify with `sha256sum -c`, and place the binaries in your system PATH.

## Updates

To update an existing installation:

```bash
solv-update
```

The updater validates cryptographic signatures, backs up the active binary, replaces it atomically, and rolls back automatically if startup validation fails.
