Active Observability & AIOps for Docker

Ultralight Go agent and FastAPI control plane designed for on-premise infrastructure. Deterministic 4-level fallback, causal incident graph correlation, zero RCE, and zero .env files.

quick install

→ Lightweight Data Plane

Go host agent consumes less than 0.1% CPU. Operates with raw Unix socket, ring buffer telemetry, and offline Docker rule evaluation.

→ Zero RCE Guarantee

Strict whitelist for container lifecycle remediation (restart, stop, isolate). Arbitrary command execution is structurally barred.

→ 4-Level AI Degradation

Cascades gracefully from Deep AI to Fast AI, then 12 deterministic Docker rules, and raw container metrics. Works completely offline.

→ Causal Incident Correlation

Correlates multi-container cascading failures into single incidents. Identifies root causes with confidence tags and manual override.

→ Encrypted Vault

Zero plaintext secrets. Credentials resolve via OS Keyring fallback to Argon2id-derived AES-256-GCM encrypted file storage.

→ Native Bilingual TUI

Bilingual Spanish and English operator terminal with Catppuccin Mocha aesthetics, split-pane navigation, and live telemetry.

Platform Support

We strictly adhere to platform honesty. Architectures marked as best-effort provide precompiled binaries but are not continuously smoke-tested by the maintainer.

Platform Architecture Support Tier Notes
Linux amd64 (x86_64) ✓ Official Primary production target. Validated on Ubuntu 22.04+, Debian 12+.
Linux arm64 (aarch64) ✓ Official Validated on ARM64 servers and Raspberry Pi 4/5.
macOS arm64 (Apple Silicon) &warning; Best Effort Binary provided. Docker Desktop socket integration works.
macOS amd64 (Intel) &warning; Best Effort Binary provided. Community reports welcome.
Windows any ✗ Unsupported Windows native host is unsupported. Run inside WSL2 with Docker Desktop.

Manual Installation & Cryptographic Verification

If your environment restricts running remote shell scripts directly, follow the manual download workflow: 

# 1. Download binary and SHA256 checksum from GitHub Releases
curl -LO https://github.com/AlvaroRiveraCarhuani/server_tracker/releases/download/v1.0.0/solv-agent-linux-amd64.tar.gz
curl -LO https://github.com/AlvaroRiveraCarhuani/server_tracker/releases/download/v1.0.0/solv-agent-linux-amd64.tar.gz.sha256

# 2. Verify cryptographic checksum
sha256sum -c solv-agent-linux-amd64.tar.gz.sha256

# 3. Extract and install into system PATH
tar -xzf solv-agent-linux-amd64.tar.gz
sudo mv solv-agent /usr/local/bin/
sudo mv solv-update /usr/local/bin/

# 4. Launch interactive terminal workspace
solv-agent --mode=tui

Updates

SOLV includes an independent updater script that downloads new releases, validates SHA256 checksums, makes an atomic backup, and rolls back if startup fails: 

solv-update
